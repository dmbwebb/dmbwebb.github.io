Duncan Webb Personal Automation

This is a set of locally run tools that Duncan Webb uses with his own Google account for research, teaching, and personal administration. It is a single-user tool and is not offered to the public.

Data notice

The tool accesses Google data only after Duncan authorizes it. It acts when Duncan requests a task or when an automation he configured runs. Some AI-assisted tasks send the minimum content needed for that task to the AI provider Duncan selected.

Read the full privacy policy before authorizing access.

What the tool does

  • Reads and manages Duncan's Gmail messages, drafts, and labels.
  • Reads and manages events in Google Calendar and entries in Google Contacts.
  • Finds, reads, creates, updates, and organizes files in Google Drive, Google Docs, and Google Sheets.
  • Authorizes short-lived Google Cloud access for a read-only Firestore export used by one research workflow.

How data is handled

OAuth credentials are stored in the macOS login Keychain. A requested workflow may save Google content or a derived output in a local project file or in private storage chosen by Duncan. The tool does not sell Google data, use it for advertising, or make it available to the public.

Control and support

Duncan can stop using the tool, delete its local credentials and outputs, or revoke its Google access at any time. Questions can be sent to dmbwebb@gmail.com.
